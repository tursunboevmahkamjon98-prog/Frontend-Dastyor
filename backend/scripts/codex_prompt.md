# Задача: извлечь список тем (оглавление) из PDF-учебников

## Источник
Папка `C:\Users\user\Desktop\pdf`. Внутри — подпапки по классам: `Синфи 1` … `Синфи 11`. Внутри каждой — PDF-файлы учебников (имена файлов разные, без единого стандарта).

## Что нужно сделать
Для **каждого** PDF-файла в этой папке (рекурсивно по всем `Синфи N`):

1. Найти страницу(ы) с настоящим оглавлением — на таджикских учебниках оно часто называется **"Мундариҷа"** (аналог "Содержание"/"Оглавление") и почти всегда расположено **в конце книги**, а не в начале.
2. Распарсить оглавление в чистый список тем/заголовков:
   - Каждая строка темы должна быть **дословно** взята из текста книги — никогда не переводить, не переписывать, не исправлять орфографию/OCR-артефакты.
   - Убрать из каждой темы её нумерацию/маркер в начале: `"14. Тарҳи адади 1"` → `"Тарҳи адади 1"`; `"§ 3. Ҳаракати шуубия"` → `"Ҳаракати шуубия"`; `"БОБИ II. Давлатдории тоҷикон"` → `"Давлатдории тоҷикон"`.
   - Убрать точки-отточия и номер страницы в конце (`"...... 25"`).
   - Не включать саму строку-заголовок "Мундариҷа"/"Содержание" как тему.
   - Убрать дубликаты (одна и та же тема иногда встречается в оглавлении и ещё раз в теле книги — достаточно одного вхождения).
   - Сохранить порядок тем как в книге.
   - Заменить устаревшие таджикские буквы на современные (это не перевод, а просто замена начертания той же буквы): `њ→ҳ`, `Њ→Ҳ`, `ѓ→ғ`, `Ѓ→Ғ`, `љ→ҷ`, `Љ→Ҷ`, `ќ→қ`, `Ќ→Қ`, `ї→ӣ`, `Ї→Ӣ`.
3. Если в PDF нет текстового слоя (сканированные страницы-картинки) — по возможности распознать текст (OCR/vision), иначе просто пропустить файл и указать его в отчёте как пропущенный.
4. Если в книге меньше 3 нормальных тем — вернуть для неё пустой список `[]`, не придумывать темы.

## Формат результата (важно — именно так, без изменений)
Один JSON-файл, где ключ — путь к файлу относительно `C:\Users\user\Desktop\pdf` (через `/`, с оригинальным именем файла как на диске, с пробелами и т.д.), значение — массив строк-тем:

```json
{
  "Синфи 5/Математика синфи 5 .pdf": [
    "Давраи тайёрӣ",
    "Дунёи рангоранг",
    "Адад ва рақами 1"
  ],
  "Синфи 7/Алгебра 7 .pdf": [
    "Функсияи квадратӣ",
    "Муодилаҳои якномаълума"
  ]
}
```

Сохрани итоговый файл как `topics_by_path.json`.

## Как это будет использовано
Результат будет загружен в базу одной командой:
```
.venv/Scripts/python.exe scripts/apply_topics_by_path.py topics_by_path.json
```
Этот скрипт сам посчитает `book_id` по пути файла и обновит таблицу `book_topics` — писать в базу самому не нужно, только отдать JSON в указанном формате.

## Приоритет
Обработай **все** PDF в папке (рекурсивно по всем `Синфи N`) — не пропускай файл, даже если кажется, что он уже мог быть обработан раньше; скрипт загрузки просто перезапишет результат. Скорость важнее идеальной точности: обрабатывай файлы параллельно/пачками. Если оглавление не нашлось или текст слишком грязный — `[]` и продолжай дальше, не останавливайся.
